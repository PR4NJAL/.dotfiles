# Pranjal's Dotfiles

Curated dotfiles and configuration for a fast, minimal Arch Linux setup using Hyprland.

## Overview

This repository stores configuration snippets and dotfiles I use daily. It is designed to be
easy to inspect, reuse, and adapt — not a one-size-fits-all installer. Keep your own
backups and review configs before applying them.

## What's Included

- greetd: display/login manager configuration
- hyprland.conf: Hyprland window manager config
- regreet.toml: extra greetd/related settings

(See the `greetd/` folder for these files.)

## Tech Stack

- **OS:** Arch Linux
- **WM:** Hyprland
- **Terminal:** Kitty
- **Editor:** Neovim
- **Multiplexer:** Tmux
